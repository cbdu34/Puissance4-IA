# Puissance4-IA
Un jeu de Puissance 4 codé en Python (Tkinter) avec une véritable IA imbattable. Grâce à l'algorithme Minimax et à l'élagage Alpha-Beta, l'ordinateur anticipe 5 coups à l'avance. Le code intègre du calcul matriciel via Numpy et optimise ses décisions en analysant le centre de la grille. Projet entièrement réalisé en autonomie à 12 ans.
